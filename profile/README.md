# Moran Extensions

实用浏览器插件工具集，每个插件独立开发和发布。下载后按各仓库说明安装到 Chrome 或桌面版 Edge。

| 插件 | 功能 | 下载 |
| --- | --- | --- |
| [填记 · 输入历史](https://github.com/moran-extensions/tianji) | 记住普通输入框的历史值，点击字段旁的按钮搜索回填 | [最新版本](https://github.com/moran-extensions/tianji/releases/latest) |
| [知页 · 网页翻译](https://github.com/moran-extensions/zhiye) | 点击翻译网页，支持双语对照、恢复原文和本机缓存；需自备 API Key | [最新版本](https://github.com/moran-extensions/zhiye/releases/latest) |
| [秘匣 · 电脑验证码](https://github.com/moran-extensions/mixia-extension) | 导入加密备份，离线生成验证码，支持可选锁屏与加密备份 | [最新版本](https://github.com/moran-extensions/mixia-extension/releases/latest) |

安装包和使用方法都在对应仓库。Edge 尚未实测，兼容范围以各仓库说明为准。问题和建议请提交到对应插件的 Issues。
